# Protolude1

Le prérequis: Il faut trouver le handgun dans la forêt pour ensuite pouvoir ouvrir les grandes portes du fort et ainsi avoir accès au petit village à l'intérieur.
Piège: Si le joueur se positionne sur le puit, il perd et est téléporté vers un autre endroit dans le map.
L'objet qui a de la physique: Le sac de farine dans le marché à l'intérieur du fort qui tombe (pas visible par le joueur).
